# Image Macro v16 실제 클릭 검증

첨부 이미지 17장과 [scikit-image 공개 샘플](https://scikit-image.org/docs/stable/auto_examples/data/plot_general.html) 6장을 사용했습니다. 표본에는 40×40 아이콘, 한글 UI, 회색조 사진, 반복 줄무늬, 흑백 실루엣, 복잡한 컬러 그림, 우주비행사·벽돌·카메라·고양이·커피·동전 사진이 포함됩니다.

실제 Windows 테스트 창에 시드가 고정된 위치로 이미지를 표시했습니다. 화면 표시는 Tk 갱신 요청 직전부터 계산하며 DwmFlush를 수행했고, 클릭은 대상 위젯이 받은 버튼 해제 이벤트를 사용했습니다. 모니터는 2560×1440 150%와 1920×1080 125%입니다. 큰 원본은 테스트 창에 맞춰 최대 890×690으로 등록하고, 전역에서는 등록 크기 100%, 검색 범위 지정에서는 등록 크기 80%로 표시했습니다. 각 버전에서 이미지당 두 조건을 한 차례씩 재현했습니다.

| 조건 | 버전 | 인식 중앙값 / 최장 | 실제 클릭 중앙값 / 최장 | 200ms 이내 |
|---|---|---|---|---|
| 듀얼 모니터 전체 · 원본 크기 | v15 | 108.2 / 263.5ms | 145.6 / 297.5ms | 20/23 |
| 듀얼 모니터 전체 · 원본 크기 | v16 | 89.5 / 138.0ms | 127.4 / 200.5ms | 22/23 |
| 창 범위 지정 · 80% 크기 | v15 | 66.3 / 629.4ms | 102.0 / 666.4ms | 22/23 |
| 창 범위 지정 · 80% 크기 | v16 | 50.2 / 75.0ms | 75.9 / 131.5ms | 23/23 |

v16은 46/46회 목표 위젯에 클릭을 전달했습니다. 좌표 오차 최대는 0.5픽셀입니다. 200.5ms를 기록한 회차는 40×40 아이콘의 듀얼 모니터 전체 검색입니다. 나무 실루엣의 80% 크기 클릭은 666.4ms에서 89.2ms로 개선됐습니다. 도시 반점 그림의 전체 검색 클릭은 297.5ms에서 135.2ms로 개선됐습니다.

별도의 오프라인 시험에서 다른 그림만 둔 23장에서는 클릭 후보를 반환하지 않았습니다. 20장은 미검출, 3장은 후보 검사 미완료였습니다. 이후 정답 그림을 추가하자 23장 모두 올바른 위치를 찾았습니다. 수치는 전용 테스트 창에서 재현한 결과이며 실제 게임·유튜브 장면의 클릭 시간을 나타내지 않습니다.
